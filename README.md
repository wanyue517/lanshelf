# LanShelf

**把文件拖进一台电脑的小悬浮框，其他局域网电脑就能看到。**

LanShelf 是一个面向 Windows 的轻量桌面文件架。它不需要部署服务器，不依赖云账号，每台设备既可以共享，也可以获取文件。

> **当前版本：v0.1.0 开发预览版。** 核心功能已实现首轮代码，不代表已通过真实多机验证；第一次使用请先在可信局域网的两台 Windows 电脑上测试。当前传输协议为 HTTP/WS，**尚无 TLS 加密，不适合公共或不可信网络**。

## 预览功能

- 置顶的顶部小悬浮入口：点击展开 / 收起，可通过系统托盘管理。
- 拖入文件、图片、文件夹，自动放入托管目录并加入公共文件池。
- 文件夹自动打包为 ZIP 共享（目前拖出的是 ZIP，而不是原始目录）。
- 文本快速共享为 UTF-8 文本文件。
- mDNS 自动发现局域网其他 LanShelf 设备。
- 首次使用六位配对码授权，并保存设备访问凭据。
- 已配对设备通过 WebSocket 接收更新消息，HTTP 按需下载文件。
- 本机文件可拖出到桌面或其他支持文件拖放的程序。
- 远程文件需**先点击下载到缓存**，之后即可拖出或双击打开。
- 文件搜索、网格/列表切换、本机/远程筛选、另存为、删除本机共享项。
- 系统托盘、开机自启、全局快捷键 `Ctrl + Shift + Space`。

## 快速开始

系统建议：Windows 10/11、Node.js 22+。Windows 系统需要 WebView？**不需要**，Electron 自带 Chromium。

```bash
git clone https://github.com/wanyue517/lanshelf.git
cd lanshelf
npm install
npm run dev
```

开发模式运行前，`npm run dev` 会编译 Electron 主进程和 preload，再启动 Vite 与 Electron。

```bash
npm run typecheck
npm run build
npm test
npm run dist:win
```

`dist:win` 会尝试在 `release/` 生成 Windows 安装包。建议在 Windows 机器上执行打包。

## 首次连接两台电脑

1. 电脑 A、B 均安装并启动 LanShelf，连接同一能够互相访问的局域网。
2. 两端进入「设备」页；B 在「发现的设备」中找到 A。
3. 查看 A 的「本机配对码」，在 B 的 A 设备条目下输入这 6 位数字并点击配对。
4. 等待设备显示「在线」。A 和 B 即可互相查看已共享文件，不必再次配对。
5. 拖入本机文件并等待托管完成；远端会出现对应的文件卡片。
6. 在远端首次使用前点击下载按钮；下载完成后拖到资源管理器、桌面或其他应用。

如果设备无法发现，检查两端的 Windows 防火墙放行及 UDP 5353（mDNS）、局域网客户端隔离、网段与网络配置。

## 使用须知

- **托管副本**：拖入文件会在本机 LanShelf 数据目录保存一份副本，拖入大文件需要时间与额外磁盘空间。为避免损坏数据，程序**不会移动或删除你的原文件**。
- **文件夹**：目前按 ZIP 分享，保持内部结构，但远端需要自行解压。
- **设备离线**：之前下载过的远程文件可继续打开；未缓存的远程文件不可用。
- **没有中心服务器**：必须由至少一台保存原始托管文件的设备在线，其他设备才能首次获取。
- **通信安全**：配对码只是准入控制，文件内容和访问令牌仍通过未加密局域网链路传输。不要在公共 Wi-Fi 中分享敏感文件。
- **重命名/删除**：当前只能删除自己共享的项目；删除后其他设备从共享列表消失，但已下载的缓存可能仍存在。
- **当前不支持**：自动剪贴板监听、跨网段发现、传输续传、端到端加密、从远端直接拖出尚未下载的文件、图像内嵌预览、自动更新。

## 技术栈

Electron + Vue 3 + TypeScript + Vite + Node.js HTTP + WebSocket (`ws`) + `bonjour-service` mDNS + Archiver。

为了避免 Windows 本地原生数据库依赖问题，首版以写入磁盘的 JSON 存储轻量元数据。未来迁移 SQLite。

## 项目结构

```text
electron/
  main.ts           主窗口、系统托盘、拖出与 IPC
  preload.ts        安全桥接、拖入文件路径解析
  core/
    engine.ts       文件导入、打包、缓存和取回
    lan.ts          mDNS、设备配对、文件服务器与消息同步
    store.ts        本机元数据及配对信息持久化
    util.ts         安全文件名、配对码
shared/types.ts     主进程与 UI 共享的 TypeScript 接口
src/
  App.vue           悬浮文件架界面与交互
  style.css         轻量桌面 UI 样式
docs/
  PRODUCT.md        UI、操作逻辑和后续能力
  ARCHITECTURE.md   协议、安全边界和工程设计
```

## 开发规范

- 所有文件路径操作在 Electron 主进程完成，UI 不暴露原始路径。
- 设备接入必须配对；文件接口验证令牌。
- 首版优先确保「拖入 → 远端看到 → 下载 → 拖出」可运行，再优化无感拖出。
- 不内置云端上传、远程控制或互联网中转能力。
