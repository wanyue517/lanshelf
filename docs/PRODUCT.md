# LanShelf UI 与交互（Tauri 2）

## 产品定位

轻量局域网共享文件架。目标：无需选择接收设备，安装后通过悬浮小入口共享文件。Windows 优先，未来兼容 macOS/Linux。

## 核心结构

### 顶部悬浮入口
- 固定顶部居中、无边框、置顶、半透明背景。
- 默认约 196 × 52 DIP，点击展开到 472 × 580 DIP。
- 系统托盘可展开/退出，Ctrl + Shift + Space 快速打开。
- 拖入文件自动展开，支持快速投放。

### 共享文件页
- 顶部：名称、已配对在线设备数。
- 工具：搜索、添加文件、共享文本、网格/列表切换。
- 筛选：全部 / 本机 / 其他设备。
- 文件卡片：文件类型、名称、大小、来源、缓存下载、另存、删除。
- 双击：打开文件；远端未缓存文件自动下载后再打开。
- 当前 Tauri 2 Windows 版本**尚不能从文件架直接拖出到其他应用**。不显示虚假的拖拽可用状态。

### 设备页
- 本机验证码、有效期。
- 已配对设备在线/离线状态。
- 自动发现新设备，输入对方验证码配对。

### 设置页
- 开机启动、快捷键、文件夹 ZIP 规则、安全限制。
- 后续支持缓存大小、清理策略、设备重命名、撤销配对。

## 后续高价值功能

1. Windows OLE 原生文件拖出（最优先）。
2. 文件大图预览、PDF/代码快速预览。
3. 剪贴板文字/截图共享（默认显式开关，考虑隐私）。
4. 多文件批量导出和搜索排序。
5. 下载缓存大小限制与自动清理。
6. TLS、可信设备授权与身份撤销。
7. 传输历史、带宽/进度、失败重试。
8. 多显示器窗口定位、可调大小、拖拽时防止自动收起。
9. 其他设备缓存副本接力，源设备离线仍能访问。
