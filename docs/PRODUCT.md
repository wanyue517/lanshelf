# LanShelf 产品与交互规划

## 1. 产品定位

在多台可信局域网电脑之间，提供一个像「桌面公共暂存架」一样的共享入口。

核心体验：**安装即常驻、拖入即共享、无需选择接收设备、按需取回。**

## 2. UI 页面

### 2.1 顶部悬浮入口（已实现）

- 默认位于当前显示器可用区域的顶部中央，约 196 × 52 DIP。
- 显示图标、软件名称、共享文件数量和展开标识。
- 点击展开到约 472 × 580 DIP；点击收起回到极简入口。
- 系统托盘支持展开、缩小、退出。
- 支持全局快捷键 Ctrl + Shift + Space。
- 文件拖入入口时尝试自动展开。

### 2.2 文件架（已实现）

- 顶栏：品牌、在线已配对设备数、收起按钮。
- 一级标签：共享文件 / 设备 / 设置。
- 文件区：搜索、添加文件、添加文本、全部/本机/其他设备筛选、网格/列表。
- 文件卡片：类型标识、文件名、大小、来源、下载缓存、另存、删除（仅自己）。
- 双击打开文件；本机或已缓存远端文件可直接拖出。
- 底部拖入提示及当前设备名；空态提供直接添加按钮。

### 2.3 设备（已实现）

- 本机动态 6 位配对码，5 分钟轮换。
- 已配对设备显示在线状态。
- 新发现设备通过输入**对方**配对码建立信任。
- 不把局域网里未配对的设备默认当成可信设备。

### 2.4 设置（部分实现）

- 开机自启、快捷键说明、存储模式、当前安全限制。
- 后续加入缓存配额、下载目录、设备命名、窗口定位与透明度。

## 3. 重要交互状态

| 场景 | 行为 |
|---|---|
| 没有文件 | 空状态 + 添加入口 |
| 拖入文件 | 主进程建立托管副本，完成后发布列表更新 |
| 拖入文件夹 | 自动压缩为 ZIP 文件 |
| 远端文件首次拖出 | 需要先下载到本机缓存；避免虚假拖放操作 |
| 远端设备离线 | 未缓存的文件不可用；缓存文件仍可打开 |
| 传输中 | 显示已接收字节和下载进度 |
| 文件被源设备删除 | 共享列表更新，先前缓存不被强制抹除 |
| 文件名很长 | 单行省略，悬停看完整名称 |
| 传输失败 | 留在列表并显示错误，可重试 |
| 未发现设备 | 显示网络与防火墙排查提示 |

## 4. 后续功能路线

### P0：稳定性与安全

- 文件传输中断重试、下载取消、断点续传。
- 源文件哈希校验、磁盘空间预检、缓存限额及过期清理。
- TLS 加密、设备公钥绑定、撤销配对与拒绝访问。
- 原生 Windows 拖拽场景测试（资源管理器、微信、VS Code）。
- 开机自启稳定性、安装包与自动更新链路。

### P1：更完整的日常使用

- 自动剪贴板文本/截图共享（需可关闭及隐私范围设置）。
- 图片、PDF、文本快速预览。
- 文件置顶、收藏、最近使用、时间筛选。
- 批量选中、批量保存与批量删除。
- 点击窗口外自动收起（正在拖拽或下载时不收起）。
- 多显示器定位、贴边吸附、可调整悬浮框大小。

### P2：提升无感使用体验

- Windows 虚拟文件 IDataObject/CFSTR_FILECONTENTS 实现「未下载直接拖出，按需提供内容」。
- 多副本缓存：源设备关机后可从其他缓存节点获取。
- 手机/平板通过本地浏览器访问、二维码扫码接入。
- 多个独立文件空间（办公、临时、个人），权限隔离。
- 文件重复检测、局域网带宽控制、传输队列。

## 5. 产品原则

- 默认界面最小化，而不是功能隐藏导致不可发现。
- 批量操作要明确告知「先选择文件」；不能仅展示无解释的禁用按钮。
- 任何跨设备不可用状态要可理解，不显示假在线与假成功。
- 共享敏感文件前明确显示网络安全与权限范围。
- 尊重源设备对内容的控制权。
